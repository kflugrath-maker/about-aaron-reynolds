# Aaron Reynolds Creepy Books

A kid-friendly classroom website exploring Aaron Reynolds' Creepy books.

## GitHub Pages

1. Upload all files in this folder to a GitHub repository.
2. Make sure `index.html` is in the repository root.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save and wait for GitHub Pages to publish the site.

The website is self-contained, so the images and interactive content are included in `index.html`.
